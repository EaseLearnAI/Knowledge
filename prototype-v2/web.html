安Anthropic 增长团队 ·5 分钟阅读·1 周前收藏
AI 摘要 · 4 个关键点
  • 不要做 100% 准确率的功能——评测比 prompt 更重要，先建立可量化的评估集。
  • 让用户改 prompt，而不是改 UI；把控制权交给用户能显著降低产品复杂度。
  • Agent 时代的核心竞争力是「工作流设计」，而非单点模型能力。
  • 慢公司也能赢——用有时间打磨 0.1 像素的细节，构建长期护城河。

过去一年，我在 Anthropic 观察到很多和直觉相反的产品结论。第一个就是：不要追求 100% 准确率。大多数团队把时间花在调 prompt 上，但真正拉开差距的是评测体系。

第二，把 prompt 的控制权交给用户。我们一度想用复杂的 UI 去「引导」用户，后来发现，让用户直接编辑 prompt，反而更快、更满意。

第三，Agent 时代，产品的护城河从模型转移到了工作流设计。谁能把一个复杂任务拆解、编排得更顺，谁就赢。
