# 前端接入指南

## 最短接入流程

1. 注册或登录，安全保存 `accessToken` 和 `refreshToken`；
2. 添加视频时生成 UUID，放到 `Idempotency-Key`；
3. `POST /api/v1/captures` 收到 `202` 后立即在列表显示“处理中”；
4. 轮询 `GET /api/v1/tasks/{id}`，或连接任务 SSE；
5. `completed` 后读取 `GET /api/v1/items/{sourceId}`；
6. 详情页直接消费 `copywriting` 与 `transcript.segments`。

## TypeScript 类型

```ts
type TaskStatus = "queued" | "processing" | "completed" | "failed";

type ProcessingTask = {
  _id: string;
  sourceItemId: string;
  status: TaskStatus;
  stage: string;
  progress: number;
  statusMessage?: string;
  startedAt?: string;
  updatedAt?: string;
  completedAt?: string;
  error?: { code: string; message: string };
};

type SourceItem = {
  _id: string;
  title: string;
  platform: string;
  status: "processing" | "completed" | "failed";
  tags: string[];
  isFavorite: boolean;
  transcript?: {
    text: string;
    segments: Array<{ startMs: number; endMs: number; text: string }>;
  };
  copywriting?: {
    oneSentenceSummary: string;
    whyWorthWatching: string;
    keyPoints: string[];
    chapters: Array<{
      title: string;
      startMs: number;
      endMs: number;
      summary: string;
    }>;
    actionItems: string[];
    tags: string[];
    markdown: string;
  };
};
```

Tag 与收藏状态通过 `PATCH /api/v1/items/{sourceId}` 更新；客户端应在远端成功后再落本地缓存。删除使用 `DELETE /api/v1/items/{sourceId}`。

## 登录请求封装

```ts
const API_BASE = "http://127.0.0.1:3100/api/v1";

async function apiFetch(path: string, init: RequestInit = {}) {
  const token = localStorage.getItem("accessToken");
  const response = await fetch(`${API_BASE}${path}`, {
    ...init,
    headers: {
      "Content-Type": "application/json",
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...init.headers,
    },
  });
  if (response.status === 204) return null;
  const payload = await response.json();
  if (!response.ok) throw payload.error;
  return payload.data;
}
```

正式 App 不应把刷新令牌放普通 `UserDefaults` 或浏览器可读明文中；iOS 使用 Keychain，Web 优先使用受保护 Cookie/BFF 方案。

## 创建和跟踪任务

```ts
const task = await apiFetch("/captures", {
  method: "POST",
  headers: { "Idempotency-Key": crypto.randomUUID() },
  body: JSON.stringify({
    url,
    quality: "balanced",
    language: "zh",
  }),
});

const timer = setInterval(async () => {
  const latest = await apiFetch(`/tasks/${task._id}`);
  updateCard({
    sourceItemId: latest.sourceItemId,
    status: latest.status,
    progress: latest.progress,
    message: latest.statusMessage,
    elapsedSeconds: latest.startedAt
      ? Math.max(0, (Date.now() - Date.parse(latest.startedAt)) / 1000)
      : undefined,
  });
  if (latest.status === "completed" || latest.status === "failed") {
    clearInterval(timer);
  }
}, 1500);
```

## UI 状态映射

| API 状态 | UI 文案 | 用户操作 |
|---|---|---|
| `queued` | 已收藏，等待解析 | 可离开页面 |
| `processing` | 正在解析 `progress%` | 查看实时日志 |
| `completed` | 已完成 | 打开摘要、章节、转录 |
| `failed` | 解析失败 | 展示任务错误，不删除收藏 |

`progress` 表示后端真实完成的处理里程碑，不是按时间自动增长的预测值。没有提供方精确百分比时，前端应保持当前进度并继续显示真实 `statusMessage` 和已用时，不应通过定时器伪造平滑进度。

## 本地开发终端

打开 `http://127.0.0.1:3100/terminal`，填入 `.env` 的 `WEB_TERMINAL_TOKEN`。页面会实时显示请求开始、响应状态、CLI stdout/stderr、转录和文案阶段，敏感字段会被过滤。
