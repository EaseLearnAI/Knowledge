# 数据归属与同步

## 权威来源

| 数据 | 权威来源 | iOS 本地职责 |
|---|---|---|
| 用户、会话 | 后端 | Keychain 保存令牌 |
| 处理任务与状态 | 后端 | 展示和恢复中的临时状态 |
| 登录用户内容 | 后端 `SourceItem` | 资料库缓存 |
| Tag、收藏、删除 | 后端 | 乐观展示前先完成远端写入 |
| Onboarding、设备偏好 | iOS | 唯一来源 |

## 当前写入链路

1. iOS 创建本地处理中条目，并携带幂等键提交 `/captures`。
2. 后端创建 `ProcessingTask`，完成后写入 `SourceItem`。
3. iOS 轮询结果并缓存内容，同时保留远端 task/source ID。
4. Tag、收藏使用 `PATCH /items/{sourceId}`；删除使用 `DELETE /items/{sourceId}`。
5. 远端成功后再更新本地缓存，避免显示服务端未接受的最终状态。

## 旧本地数据

历史版本可能已清空 `remoteSourceItemID`。本次结构重组不猜测映射并覆盖旧数据，避免误合并或误删。正式切换“启动时以后端列表覆盖缓存”前，应先用 source URL、账号与时间窗口制定一次性迁移策略，并加入回滚与冲突统计。
