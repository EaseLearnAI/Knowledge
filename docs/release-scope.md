# Memo 上线范围

## 一期：最小可用版本

主分支只发布这一条闭环：

1. 产品介绍；
2. 手机号或邮箱注册、登录；
3. 两页首次引导；
4. 粘贴公开链接；
5. 提取标题、正文和来源信息；
6. 生成摘要、关键观点与 Tag；
7. 收藏、查看详情、搜索和删除。

一期不展示 AI 问答入口，iOS 原生桥接也不接受 `chat` 动作。内容分析仍可以使用端侧模型、本地提取算法或后端配置的摘要模型，因为它属于“单次内容处理”，不包含多轮对话、上下文维护和问答用量。

## 二期：知识问答

完整的知识问答、引用卡片和对话历史保存在远端分支：

- 分支：`codex/phase2-ai-chat`
- 基线提交：`42dff1c`

二期开发时从该分支继续，不需要从一期主分支恢复已移除的产品入口。开始二期前，应先把当时的主分支合入该分支，解决认证、数据模型和界面的差异，再继续开发与验证。

## 分支策略

- `main`：始终保持可以作为一期发布候选的最小产品。
- `codex/phase2-ai-chat`：长期保留二期完整能力，不随一期的减法提交移动。
- 二期开始时新建实际开发分支，例如 `codex/phase2-ai-chat-implementation`，避免直接在保留分支上持续堆叠实验提交。
